# Evaluation Assets

- `trigger_cases.jsonl` contains 60 routing cases.
- `synthetic_cases.jsonl` contains 12 compact atomic manuscript and revision scenarios.
- `composite/` contains 6 longer cases with multiple interacting defects, dispersed evidence, valid sub-results, and decoys.
- `rubric.md` defines scoring dimensions and reporting rules.

The cases are synthetic and contain no real manuscripts, referee reports, editor correspondence, or unpublished third-party research. See [Synthetic Case Design](../docs/CASE_DESIGN.md) for construction and quality gates.
